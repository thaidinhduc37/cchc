🎯 Flow hoạt động theo lĩnh vực
Scenario 1: Chọn lĩnh vực → Flow Guidance
User: "hướng dẫn làm hộ chiếu"
   ↓ intent_detector.py (detect domain: xuatnhapcanh)
   ↓ flow_engine.py → load data/xuatnhapcanh/flow.json
   ↓ Navigate questions → flows
   ↓ 
Response: "Chào bạn! Rất vui được hỗ trợ bạn..." + options
Scenario 2: Domain-specific RAG Q&A
User: "phí làm hộ chiếu bao nhiêu?"
   ↓ intent_detector.py (detect domain: xuatnhapcanh)
   ↓ rag_engine.py → load data/xuatnhapcanh/
   ↓ Priority: question.xlsx → documents/ → gemma:2b
   ↓
Response: "Phí làm hộ chiếu là..." + [Hướng dẫn làm hộ chiếu] button
Scenario 3: Multi-domain query
User: "so sánh thủ tục làm CCCD và hộ chiếu"
   ↓ intent_detector.py (detect: cancuoc + xuatnhapcanh)
   ↓ rag_engine.py → query cả 2 domains
   ↓ Aggregate results + suggest specific flows

💡 Key Design Decisions
1. Flow-First Approach

Flow guidance là chức năng chính
RAG Q&A là supporting function
Luôn suggest flow khi có thể

2. Hybrid Search Strategy

Excel Q&A → Vector RAG → LLM generation
Tận dụng structured data trước

3. Context-Aware

Track conversation state
Smart context switching
Memory-efficient design

4. Performance Optimized

Cache-heavy for flow navigation
Async processing for RAG
Smart fallback strategies
